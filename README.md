# Fatharony Fatwa — Portfolio

Personal portfolio built with React, Vite, Framer Motion, and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Where to edit content

Almost everything lives in `src/data.js` (profile, about, stats, experience, education, projects, skills).
The CV download is `public/cv-fatharony-fatwa.pdf` and the profile photo is `public/img/face.webp`.
